# 留白编辑部

一个可独立运行的擦除诗工作台。底稿、诗笺与交互代码均为原创，MIT 开源。

## 核心玩法

不是随机挑选现成诗句，也不调用模型。你从三篇完整的原创散文里选择单个词块，保留原文顺序；再决定哪些词块之后换行。相邻关系、词语缺席与呼吸位置会即时改变你写出的诗。

- 三篇底稿：《在末班车之后》《搬家那一天》《星期天的菜市场》，各有两组相互牵引的预设意象。
- 委托模式有词块预算、行数与意象约束；自由模式没有达标线。
- 每次选择或分行都会更新诗、词块/行/字数、原文保留比例和各行长度。没有 AI 质量评分。
- 点词块保留/擦除；Shift + 点击连续保留一段；原生按钮支持 Tab/空格。
- 开启“合上黑墨”可用擦除诗的阅读方式重看原文。词语仍可直接操作。
- 在下方词块链的 ↵ 按钮插入或取消换行。
- 选择与分行支持 100 步撤销、重做；示例和清空也可撤销。
- 每篇底稿有独立自动草稿；可额外收藏最多 12 份快照，并跨底稿恢复继续编辑。
- 导出 UTF-8 文字或 SVG 诗笺。SVG 中的长行会按显示宽度分段，以免截断；工作台的原始分行与文字导出不变。

“看看一种可能”只提供一个可修改的入门样例，不是标准答案。所有委托都有大量可行组合；达标只代表满足练习条件，不能评判诗的价值。

## 独立运行

Node.js 20 或更新版本。无第三方运行时或构建依赖，无后台、账号、密钥与付费服务。

```sh
cd demos/erasure-poetry
npm ci
npm test
npm run build
npm start
```

访问 `http://localhost:4176`。可用 `PORT=8080 npm start` 改端口。服务器只读 `dist/`，带路径边界检查。

## 构建与部署

`npm run build` 将 `index.html` 与 `src/` 复制为独立静态目录 `dist/`。可以将此目录部署到任何静态托管；相对资源路径支持子目录部署。必须通过 HTTP(S) 打开，不能直接双击 HTML，因为使用浏览器 ES modules。

在线地址由发布流程完成后补充。尚未发布时，不将本地构建当作上线。

## 测试与验收

`npm test` 使用 Node 内置 test runner，共 27 项测试：三份委托的成功路径、意象缺失、超预算、行数不足、选词排序、范围选择、损坏输入归一化、分行、撤销重做分支与容量、SVG 转义和长行处理、序列化恢复。

另外通过 `node --check src/app.js`。以上为单元/语法检查，不能代替浏览器实测。具体浏览器验收步骤见 [QA.md](QA.md)，实际执行结果由发布者补充。

## 隐私与限制

- 内容仅写入当前浏览器的 localStorage，不上传。换浏览器、清除网站数据或无痕窗口关闭可能丢失，请导出备份。
- 存储被浏览器阻止时仍可编辑和导出，但刷新会丢失内容；界面显示提示。
- 标题不是选择/分行撤销栈的一部分。切换底稿会清空本次撤销栈，但自动草稿与收藏仍保留。
- 意象标签是预设编辑提示，不是自然语言理解或心理分析；标点也属于可选词块。
- 没有多人同步、云端保存、AI 生成与语义打分。
- SVG 中的中文字形依赖打开文件时设备字体；长标题限制为 30 字。
- 真实手机触摸与跨浏览器兼容性未由单元测试覆盖。
