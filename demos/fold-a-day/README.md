# 把今天折成一首诗

在很快的世界里，给很小的事情留一点位置。

选择一个日常场景、一种心情、一个意象，从原创中文句库组合成四行小诗；可直接编辑诗句与标题，保存为 PNG 诗笺。米白纸张、棕色印章，适配手机和桌面。

## 在线体验

https://hakuya-fold-a-day.golden-berry-3772.chatgpt.site

站点公开。页面提供本项目源码 ZIP 下载（每次构建重新生成，含 MIT LICENSE），源码亦收录在此 GitHub 仓库中。所有选项和诗句仅在浏览器本地处理，不上传、不持久存储；刷新会重置。

## 独立运行

Node.js 22+ / npm，无第三方依赖，也不需要 AI API。

```sh
cd demos/fold-a-day
npm ci
npm run dev
```

打开 http://127.0.0.1:4173 。修改后运行 `npm run build` 并刷新，或重启 dev。端口可通过 `PORT=4321` 覆盖。

```sh
npm test        # Node 内置测试
npm run build   # 独立静态产物 dist/
npm run check   # 测试 + 构建
npm run preview # 预览已有 dist/
```

## 功能与实现

- 5 个场景 × 5 种心情 × 5 个意象，搭配 135 种变体序号。
- 「折成另一首」按选项重新组合；「把选择交给偶然」随机选择。
- 不是 AI 即时生成：界面明确说明使用本项目原创句库，不冒充大模型服务或引用诗人作品。
- 标题与诗句可修改；覆盖手写诗句前询问，取消不会丢失文本。
- Canvas 按文本自动换行和增加高度，生成无外部图片依赖的 PNG。
- 不引入账号、数据库、付费服务或遥测。

## 测试和边界

6 个 Node 测试（含导航链接回归）覆盖全部 125 组选项、确定性与变体周期、非法输入、Unicode 换行和空行保留。无需网络即可运行。

诗句最多 500 字符（浏览器按 UTF-16 计数），标题最多 24 字符；视觉字体取决于系统，因此 PNG 与不同设备的显示可能略有差异。词句组合不保证每次唯一，诗歌质量是主观的，可以自由改写。下载由浏览器提供，手机可能需要在下载/文件应用中保存。

`dist/` 可独立部署到静态托管服务。托管配置不随公开源码提交；本项目可独立部署，不影响未来其他技术栈。
