# 渡口摆渡人

一条小船，两岸牵挂。原创、无需倒计时的河畔装载逻辑游戏：安排乘客和货物上左舷或右舷，在载重、配平、留岸照看与有限船票之间找到一条完整方案。不是路线寻路或等待潮汐的换皮；所有行动围绕**谁与谁留岸、谁往返、装到哪一舷**展开。

## 三份委托

1. **早市第一船**：狐狸、白鹅、谷子；载重 4、重量差 ≤3、2 件、7 张船票。最短 5 航。
2. **雏鹅回家**：加入护林员与雏鹅；载重 4、重量差 ≤2、2 件、9 张船票。留岸的护林员可以看护冲突组合，雏鹅需陪伴。最短 7 航。
3. **迁往新花园**：园丁、猫、鸟、幼苗、孩子、小狗、铜锅；载重 6、重量差 ≤2、3 件、9 张船票。需要将两件同放一舷，安排孩子的陪伴和三组照看关系。最短 7 航。

每舷最多两件。摆渡人固定居中，不计载重。停靠岸有摆渡人照看；离岸时检查留下的人与物。到岸自动卸船。空船可以往返，但也消耗一张票。非法装载只给解释，不改变状态也不扣票。耗尽船票仍未完成可撤回，不强制重玩。

## 操作

选择左/右舷，再点停靠岸上的伙伴装船；装入后自动切换另一舷，也可以手动指定。点船上伙伴下船。点击“解缆”提交本航。支持清空装载、撤回一航、重开、切换委托。所有按钮均可键盘聚焦操作。

“问问老船夫”使用本地确定性广度优先搜索，从当前靠岸状态计算剩余船票内的最短解，给出下一航两舷安排。不会自动装船或执行。若已走进预算死路，会建议撤回。局部离岸安全不等于后续必然能完成。

## 本地运行

Node.js 18+，零第三方依赖，各 demo 可单独运行。

```sh
npm ci
npm test
npm run build
npm start
```

打开 http://localhost:4173 ，可用 `PORT=4186 npm start` 指定端口。`npm run build` 输出纯静态 `dist/`，可放在任意静态主机。

- `src/engine.js`：委托、纯规则、状态转移与最短路径搜索。
- `src/app.js`：双岸装船、配平、交互、记录、提示及撤回。
- `test/engine.test.js`：30 项测试，覆盖无效载重/配平、留岸规则、陪伴、三关最短可解性、预算、全部安全可达状态与不同效率结局。
- `QA.md`：明确解法与浏览器实测记录。

## 数据与许可

只在 `localStorage` 的 `ferry-balance-records` 中保存各委托最佳航数。禁用存储仍可玩；进行中的局面不保存，刷新后重置。无账户、联网生成、追踪、外部字体、CDN 或付费服务。人物、场景与游戏重量均为虚构，不作为真实航运安全指南。
