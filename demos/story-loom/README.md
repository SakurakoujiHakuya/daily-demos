# 双声道小说 / Story Loom

把两个人的时刻织成一个故事。三篇原创、每篇八张桥段卡，亲手重排同一组事实，让人物的行动与回应接起来，再决定谁留下最后一句。

## 快速开始

需要 Node.js 18+；零运行和开发依赖。

```sh
npm ci
npm test
npm run build
npm start
# http://localhost:4183；可用 PORT=xxxx 指定端口
```

`dist/` 是完整静态站点，也可以直接将四个应用文件放到支持 ES modules 的 HTTP 静态服务器。无需账户、API Key 或后台服务。

## 核心交互

- 点选两张卡片后交换，或用 ↑ / ↓ 在阅读序列里逐格移动；数字从左到右、再向下读。
- 结构校读检查 **同一声道时间不倒退**、**回应所需行动已经出现**、**必要桥段未被省略**。不同声道可以交错回望，不是全局时间排序。
- 可省去任何卡片并随时放回；两段标记“可留白”的内心独白可以合法省略，必要桥段缺失会得到明确解释。
- 因果连线显示具体桥段关系；节奏报告声道切换次数、连续独白长度、相邻异声道的意象呼应。没有任意分数，也没有唯一“最佳”阅读。
- 每篇有三种余音：A 声道收尾、B 声道收尾、两段内心独白都省略的留白版。仅在结构成立后展示定稿旁批。
- 可调整阅读前景，在试读中突出一个声道；另一声道不消失，不会偷偷放宽约束。
- 单选卡片改写正文；撤回、重做；逐篇本地保存；JSON 导入导出；纯文本导出。

## 故事与可复现编排

卡片 ID 可在按钮的无障碍名称中找到；A/B 对应页面两条声道，编号是各声道内部顺序。

| 故事 | A / B | 初始冲突 | B 结尾 | A 结尾 | 双留白结尾 |
| --- | --- | --- | --- | --- | --- |
| 借来的阳台 | 林夏 / 周伯 | B2 回应早于 A2 行动 | 春天拥有了一个空位 | 离开，也是一种安放 | 没有说出的归期 |
| 停电后的第三拍 | 阿澈 / 许页 | B3 早于 B2，B 声道时间倒退 | 让空白也署名 | 一个人终于不抢拍 | 一段无法解释的安静 |
| 把配方留在门外 | 沈陶 / 小满 | A4 早于 A3，A 声道时间倒退 | 第一炉，用自己的名字 | 带着不同的味道离开 | 两张配方挨在一起 |

三篇通用的可行序列（并非唯一解）：

- **紧密交错 / B 收尾**：`A1 B1 A2 B2 A3 B3 A4 B4`。
- **长独白 / A 收尾**：`B1 A1 A2 B2 B3 B4 A3 A4`。
- **留白版**：使用任一上述可行序列，再省去 `A3` 和 `B3`，保留六个必要桥段。
- `A2 → B2 → A4` 是跨声道回应链；每个声道内始终按编号递增。

### 从初始散稿快速到达不同结果

1. **阳台**：选中 `B2`、`A2` 并交换，得到 A 结尾；再交换末尾 `B4`、`A4`，得到 B 结尾；省去 `A3`、`B3` 得留白版。
2. **排练**：选中 `B3`、`B2` 并交换，得到紧密交错的 B 结尾；交换末尾 `A4`、`B4`，得到 A 结尾；省去 `A3`、`B3` 得留白版。
3. **面包房**：选中 `A4`、`A3` 并交换，得到 B 结尾；交换末尾 `A4`、`B4`，得到 A 结尾；省去 `A3`、`B3` 得留白版。

## 范围与隐私

文本完全原创、人物与情节虚构。浏览器只用 `localStorage`，不会上传改写或备份。结构检查是确定性规则，**不分析用户改写后的语义**；页面和导出都明确说明。自由改写不会修改卡片的时间或因果标签。换故事保留各自草稿，撤回栈只属于当前打开的故事。

## 工程

- `engine.js`：原创数据、不可变移动/交换/留白、验证、旁批、纯文本导出。
- `app.js`：可访问 DOM 交互、本地保存、编辑历史、文件备份与导入。
- `style.css`：纸本编辑风格，双声道砖红 / 蓝灰、响应式布局与 reduced-motion。
- `test/engine.test.js`：35 项 Node 原生测试，覆盖三篇多结尾、冲突、动作边界、导入验证及文本导出。
- `scripts/build.js`：只复制四个静态应用文件；不打包凭证、源码仓库或私有数据。
- `scripts/serve.js`：无依赖本地静态服务。

部署详情与实际浏览器验证见 `deployment-info.json` 和 `QA.md`。应用代码、原创故事与界面均采用 MIT 许可。
