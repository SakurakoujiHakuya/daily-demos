# 午夜小食堂

一个原创、中文、移动优先的七夜回合制经营游戏。把生活里的热饭、人情和账本变成可操作的策略，而不是阅读幻灯片。

## 核心循环

1. 阅读当晚天气、客人口味与预算，选择最多三道菜和统一加价。
2. 逐份采购或退回食材。粗配一篮只会把菜单涉及食材补到两份，不会预测或保证实际点单。
3. 开门后，为每位客人选择两份食材、烹饪方式并出餐。可手动配菜，也可按配方选好食材再自己选择做法。
4. 预算、口味、点单匹配决定满意度，进而影响口碑。没备够可以做别的已知菜，也可以谢客；错误配方消耗库存但不会推进客人。
5. 打烊支付租金，所有鲜食损耗，米饭和面条过夜保留。七夜后得到五种不同结局之一，或在资金耗尽时提前结束。

策略维度：菜单共享食材与成本、口味覆盖、采购数量、库存风险、加价与口碑、替代菜与谢客。没有真实等待，没有随机按钮伪装成经营。相同故事种子确定相同天气、客人和点单，可比较不同策略。结局包含节约高口碑、商业盈利、街坊认可、普通生存与破产。

## 本地运行

需要 Node.js 18 或更新。没有第三方 npm 依赖，也不使用外部字体、图片、API 或凭据。

```sh
npm ci
npm start
# http://localhost:4173
```

可用 `PORT=4183 npm start` 更换端口。浏览器需要支持 ES Modules、localStorage、dialog。推荐现代 Chrome、Firefox 或 Safari。不要用 file:// 双击打开，模块加载通常会被浏览器限制。

## 测试与构建

```sh
npm test
npm run build
node scripts/serve.mjs --dist
```

- `src/engine.js`：无 DOM、无网络、无隐式随机的纯状态转换引擎。
- `src/app.js`：界面、操作处理与本机存档。
- `test/engine.test.js`：Node 内置测试覆盖状态隔离、确定性、不同种子、采购和退款、金额/数量边界、菜单上下限、锁定阶段、订单偏好、配方、失败消耗、预算惩罚、替代出餐、谢客、损耗、租金、完整七夜、结局、重置与防重复结账。
- `scripts/build.mjs`：复制静态文件到 `dist/`，没有打包依赖。

## 部署

把 `dist/` 的全部内容部署到任何静态 HTTP 托管服务。所有 JS/CSS 使用相对路径，可放在 `/demos/midnight-canteen/` 子目录。页面左上角链接在新标签页打开公开仓库的源码与作品目录，独立部署无需修改导航。无需环境变量、服务端或构建密钥。

## 存档与操作

进度存在本浏览器的 `midnight-canteen-v1` localStorage 项，刷新续玩。「重走这七夜」经确认重置同一种子；「换个故事种子」新建另一组天气和客人，取消不会覆盖。操作台尚未提交的食材选择不会存档，也不会扣库存。可用键盘 Tab / Enter 操作，有焦点样式和持续的状态播报。没有倒计时、自动推进或声音。

## 规则细节

满意度 = 3 + 点单匹配（+2，否则 −2）+ 口味匹配（+1，否则 0）− 超预算金额 × 2，限制在 0–6。口碑变化 = 满意度 − 3。正确已知菜均按该菜价格收款，不论是否原订单。失败配方口碑 −3，消耗两份食材；谢客口碑 −4，不消耗食材。每夜租金 ¥12，起始现金 ¥80。鲜食打烊全部清零；粮食保留。测试可以使用内部状态构造边界；游戏 UI 不提供作弊入口。
