# 一平方米四季

原创中文阳台微型策略模拟。十二个花盆、四种作物、三种情景，用有限水与预算走过手动推进的 20 天。没有计时器、登录、外部接口、外部素材或依赖。

## 运行与部署

需要 Node.js 20 或更新版本（测试使用 Node 22）。

```sh
npm ci
npm test
npm run build
npm start
```

打开 http://localhost:4173 。也可将 `dist/` 全部文件部署到任意静态网站服务；不需要服务器逻辑，支持子目录路径。`PORT=4300 npm start` 可指定端口。

## 核心操作

1. 查看今日及未来两日天气，选择种子，点击空格播种。番茄需要右侧相邻空格。
2. 点击植物，再点击浇水、收获或移除。键盘 Tab + Enter 同样可完成全部操作，无需拖拽。
3. 土壤水分上限 4；浇水消耗 1 升储水并增加 2 土壤水分。¥4 可补 6 升储水。
4. 点击「结束今日」才推进一天。阵雨在结算开始时补每盆 2 水分并收集 3 升。
5. 水分和光照都足够才成长并恢复 1 健康；任一不足失去 1 健康，健康归零枯萎。成熟植物依旧耗水且可能枯萎。
6. 第 20 天结算之后自动收获成熟作物，未成熟作物不折现。重新开始前会要求确认，不存储本地进度。

## 可探索策略

- 萝卜：四个生长日即可成熟，向阳格在所有天气都能成长，是稳定现金流。
- 番茄：五个充足光照生长日、占两格且每日耗水 2，收入高但受天气影响。
- 罗勒：生长至少 2 日后，相邻（上下左右）的植物每日耗水减少 1，最低 1。
- 蜜源花：生长至少 2 日后，相邻番茄每个成功生长日增加 ¥2 收成，最多 ¥8。
- 左列光照减少 1；晴天可以利用墙侧，连阴雨时墙侧作物危险。番茄的延伸空间不算新的邻居。
- 成熟植物也可继续作为伴生植物，但需承担照料成本。
- 春日均衡、盛夏限水、秋雨多云。相同情景和种子严格重放天气，可比较策略。
- 得分 = 余款 + 收获盆数 × 5 + 授粉番茄天数 × 2 − 枯萎盆数 × 3。

## 结构与验证

- `engine.js`：纯状态引擎，所有动作返回新状态，确定性天气，无 DOM 或系统时钟。
- `app.js` / `style.css` / `index.html`：响应式界面与原创内联 SVG 植物。
- `test/engine.test.js`：26 项确定性测试，涵盖资源、空间、成长/死亡/恢复、伴生、季末，以及三个情景完整 20 天策略和春日授粉番茄。
- `scripts/build.js`：零依赖静态打包到 `dist/`。

已执行自动测试与静态构建。浏览器视觉与触屏实机验证交由发布流程进行，未经测试的浏览器不作兼容性承诺。需要支持原生 ES modules、structuredClone 和 dialog 的现代浏览器。

所有园艺规则均为简化虚构游戏机制，不构成真实种植建议。
