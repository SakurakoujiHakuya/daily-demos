# 创作素材导航

按用途寻找字体、图标、摄影与插画的轻量工具。不是素材镜像：只整理 12 个公开来源、独立中文说明、已核对的许可入口。搜索 → 缩小范围 → 最多三项并排比较 → 收藏 → 导出 Markdown。

## 运行

Node.js 20+，无运行时或开发依赖；本目录独立，不需要根 workspace。

```sh
npm ci
npm test
npm run build
npm start
# http://localhost:4173 （PORT 可覆盖）
```

静态输出为 `dist/`。用任何支持 ES modules 的静态服务器提供即可，不能直接双击 file:// 运行。锁文件随项目提交。

## 关键交互

- 按中文用途、名称和格式搜索，多个词按 AND 匹配；全角英文字母与大小写归一。
- 用途 / 格式 / 许可类型筛选，显示计数与可移除条件；清除筛选保留关键词。换用途时重置格式，避免沿用不适用的格式。
- URL 保存筛选与最多三项对比，可复制链接恢复相同视图；不包含收藏。
- 收藏保存在当前浏览器 localStorage，失败时仍能临时使用并导出。
- 对比用途、格式、费用、访问方式、许可摘要。收藏清单导出真实 `.md` 文件，含官网、许可出处、核对日期与注意事项。

## 内容与隐私

目录核对日期：2026-10-26。原始官方链接与核对范围见 [SOURCES.md](SOURCES.md)。每张卡片可展开许可来源。费用、条款、格式可能变化；使用前查具体作品。没有做每站所有下载流程，因此不保证所有资源免登录；卡片如实区分公开浏览与下载未知。并非法律建议或无条件商用保证。

本页不调用外部 API、不上传收藏、没有分析追踪，也不下载/再分发第三方素材。外站链接由用户主动打开，之后适用外站政策。内置几何/文字标记仅为自主界面装饰，并非第三方素材预览。无第三方字体、图片或 icon bundle。

原创代码 MIT。第三方站点名称及素材归原权利人，MIT 不覆盖它们。无合作、背书、联盟链接。

## 设计

首屏先有检索输入和结果；不设教程门槛或大幅宣传头图。次要许可细节按需展开，但卡片始终保留许可类型与费用差异。对比最多三项避免无界表格。移动端纵排，不压缩正文至不可读。

## 测试与部署

`npm test` 为 Node 原生测试（筛选组合、Unicode、空结果、URL 往返、参数清理、对比上限、收藏与导出）。浏览器测试另记在 `QA.md`，不将单元测试当作浏览器实测。

公开 Sites 部署信息见 `deployment-info.json`。独立 `.openai/hosting.json` 配置为静态 `dist/`，通过 Sites 官方 source helper 同步、打包并发布。其他静态托管只需上传 `dist/`，不需要任何凭据或付费服务。部署元数据不含凭据。
