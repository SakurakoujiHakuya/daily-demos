# 日常物证馆 · Museum of Ordinary Things

2026-10-20 的每日创意 demo。不是价格鉴定，也不是 AI 编故事：为身边的普通物件写一张郑重的展签，收藏生活中不容易被注意到的细节。

## 体验

- 常设展：6 件原创虚构展品与原创 SVG 插画，钥匙、车票、杯子、雨伞、小票、磁带。
- 我的收藏：新增、编辑、移出最多 12 件展品；类型、名称、年份、材质、地点、故事和痕迹。
- 下载 1200 × 1600 PNG 展品海报。长文会在版面容量外省略，完整文本始终在收藏及 JSON 备份中。
- JSON 备份和导入；导入合并而非覆盖，重复 ID 跳过，超过 12 件的部分不导入。
- 键盘可操作；弹窗可用 Escape 关闭；手机横向展品架、单栏详情、减少动态效果偏好。

## 独立运行

需要 Node.js 22 或更新版本。本项目没有任何第三方运行时或开发依赖，无需安装依赖即可运行。

```sh
cd demos/ordinary-museum
npm test
npm run dev
# http://127.0.0.1:4173
```

若端口占用，可用 `PORT=4174 npm run dev`。`npm run build` 输出 `dist/` 并包含干净的 MIT 源码 ZIP，`npm run preview` 预览已构建目录。`npm run check` 顺序测试并构建。所有命令只针对本项目，不依赖其他 demo。

## 部署

静态托管：运行 `npm run build`，将 `dist/` 作为网站根目录。不需要后端、数据库、密钥或账号登录。

公开体验：https://hakuya-ordinary-museum.golden-berry-3772.chatgpt.site/

在线页提供“下载源码”，不链接未确认存在的 GitHub 仓库。

## 数据与隐私

所有用户输入只在浏览器处理，收藏保存在该网站源下的 localStorage 中，没有网络上传、统计 SDK、API 或大模型调用。常设展所有内容都是虚构示例，不代表作者或用户的真实经历。海报、备份由用户主动下载。公开网站不意味着收藏公开。

清除浏览器数据、切换设备/浏览器或无痕窗口关闭都可能丢失收藏，请使用 JSON 备份。若浏览器不允许持久化，页面会提示并保留当前会话内容供下载。导入限 128 KB，只接受版本为 1 的数据，字段长度有边界，文字通过 textContent 渲染。页面图像来自本地 SVG 原创几何绘图，不加载外部资源。

## 验证与边界

`node --test` 覆盖样例完整性、输入边界、空白验证、中文/emoji/换行往返、损坏存储、导入去重、不可变编辑、容量限制、SVG 无外部加载、DOM ID 对应、隐私文案与正确源码入口。

这是单机展厅，没有账号同步、分享私藏链接或实物照片上传。图示是物品类型的原创插画，不是上传物品的照片。海报使用设备可用字体，因此不同设备文字外观略有不同。
