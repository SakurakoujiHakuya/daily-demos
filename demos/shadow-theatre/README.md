# 影子剧场

一盏灯、几张纸偶和三幕可以亲手排练的小戏。不是切换图片：纸偶位置、深度、倾角与灯位共同计算实时投影。用空间推理对齐虚线轮廓，解锁原创短句；也可以关闭目标，自由排练。

## 本地运行

需要 Node.js 20 或更新版本，无第三方运行时依赖。

```sh
npm ci
npm test
npm run build
npm start
# http://localhost:4187
# PORT=4200 npm start 可更换端口
```

build 独立生成 `dist/`。任意静态服务器或支持静态目录的托管平台都可部署此目录，不需要账户、后端、密钥或付费服务。项目不依赖仓库根目录 workspace。

公开体验：<https://hakuya-shadow-theatre.golden-berry-3772.chatgpt.site>。

## 核心玩法

- 实心是当前投影，虚线是目标。先调深度控制大小，再调横纵坐标和倾角。
- 直接拖动幕布上的影子，改变纸偶横纵位置；拖动俯视图纸偶，改变横向位置与深度。
- 所有位置也可以用具备文字标签的原生滑块调整，Tab 聚焦、方向键微调。灯的纵向位置通过滑块调整。
- 第二幕起共用光源，移灯同时改变所有影子，产生多解空间。自由排练不限灯位、不计算胜负。
- 一次拖动计一次调整。三星参考是软预算，不会限制操作或隐藏结局；可以撤销最近100次操作、重置、直接换幕或使用三级提示。
- 状态仅存当前浏览器 localStorage；被禁用时仍可游玩。切换幕会开始该幕的新排练；撤销历史不跨刷新保留。

## 三幕参考解 / 浏览器验收流程

选中纸偶后，用滑块设置数字；所有数值均在滑块范围内。一次调整定义为一个滑块提交或一次拖动。每幕参考解都应显示100%、全部绿色勾、故事和三星。

| 幕 | 灯（横/纵） | 纸偶 | 横 / 纵 / 深度 / 倾角 |
|---|---|---|---|
| 1 | 0 / 0，固定 | 归鸟 | 12 / 6 / 60 / 15 |
| 2 | 8 / -6 | 老树 | -14 / 4 / 55 / -10 |
| 2 | 8 / -6 | 小屋 | 20 / 4 / 65 / 10 |
| 3 | -6 / 4 | 归鸟 | -21 / -15 / 60 / -15 |
| 3 | -6 / 4 | 老树 | -5 / 5 / 65 / 5 |
| 3 | -6 / 4 | 小屋 | 23 / 8 / 70 / -5 |

其他验收：
1. 初始第一幕为未解，先改变深度看影子缩放，撤销后恢复；三次提示展示渐进信息和一组解。
2. 第二幕移动灯，两道影子同时改变；撤销恢复。按参考解完成。
3. 第三幕完成后，改错倾角至相差30°，完成状态应消失，撤销后恢复。
4. 开启自由排练，目标轮廓消失，吻合度显示∞；第一幕灯也可移动。
5. 刷新页面保留当前幕与所有参数；手机窄屏为上下布局，滑块仍可用。

## 数学与边界

点光源位于深度0，幕布位于100。对纸偶中心 `(u,v,z)`，投影倍数 `s=100/z`，幕布中心为 `light+(paper-light)*s`，半径为 `paperRadius*s`，倾角保持不变。此为平面剪纸的相似三角形模型，不模拟实体遮挡、半影或真实光照。

胜利判定：每个纸偶中心误差≤2、投影半径误差≤1、倾角误差≤5°。分数用于渐进反馈，不代替逐项容差判定。部分极端位置可使影子离开幕布，控制台与俯视图仍可找回；也可撤销或重置。

## 测试

`npm test` 使用 Node 内置测试，不访问网络，覆盖三幕参考解与可达性、投影公式、光源联动、固定灯、自由模式、边界、不可变状态、计数、容差、渐进提示及损坏存档。单元测试不是浏览器实测；部署后的视觉和真实操作测试由交付记录单独列出。
