# 蓝染实验室 / Resist Dye

一间原创的数字防染工坊：在 16×16 布面画蜡、折叠复制笔触、逐层浸染、脱蜡，让操作顺序留下不同深浅。不是现实染料配方或化学实验指导。

## 核心玩法

- 三个委托分别训练留白节奏、分阶段防染和四向对称。每格实际染层与目标对照，全部吻合且脱蜡后完成。
- 鼠标/触屏拖动上蜡或擦蜡，细笔与宽笔可选；左右、上下、四向折叠会复制后续笔触。
- 染色只作用于未上蜡格子，最多四层。已染浅蓝再上蜡，会保留浅蓝而非变回白色。
- 每次完整笔画、浸染、脱蜡、重置都可撤销/重做。自由工坊没有标准答案，可导出无蜡膜 SVG。
- 各委托独立草稿自动保存在浏览器 localStorage。无联网账户、分析服务或上传。

## 运行

Node.js 18 或更新版本；无第三方运行或开发依赖。

```sh
npm ci
npm test
npm run build
npm start
```

打开 http://localhost:4173 。可通过 PORT 环境变量改端口。项目独立运行，不依赖仓库根目录 workspace。

## 操作与无障碍

布面为键盘网格：Tab 进入，方向键移格，空格/Enter 使用当前工具。按钮有可访问标签，颜色状态含文字说明。显示蜡膜开关只改变查看方式，不改变实际防染。

## 测试与部署

`npm test` 为 Node 原生确定性引擎测试；`npm run build` 将 src 复制为静态 dist。可以将 dist 部署到任意静态托管。在线地址与实际浏览器验证由发布记录补充，不把单元测试当作浏览器实测。

测试覆盖防染顺序、染色饱和、对称、宽笔边界、持久化输入校验、三委托可解性与 SVG 导出。

已知限制：这是离散色阶数字模型，不模拟真实染料扩散或布料物性；撤销记录在刷新后清空，但布样保留；浏览器拒绝本地存储时会显示提示。
