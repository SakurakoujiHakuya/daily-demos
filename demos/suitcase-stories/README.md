# 行李里的远方 · Suitcase Stories

原创空间收纳策略小游戏。一只箱子、三种旅程、十四件物品：选择、旋转、移动和取出，在必需品、重量、空间与自己的偏好之间作取舍。不是航空行李建议，所有天气、旅程与数值均为虚构设定。

## 核心玩法

1. 选择海边、山中或城市旅程。清单中每种需求都要满足，且总重量不超过限制。
2. 点物品，再点箱子格子，将其旋转后外框左上角放在该格。鼠标悬停预览；手机可直接点。右侧实时显示需求、重量与期待值。
3. 从清单选择已经装入的物品可移动；旋转、取出、撤销用于调整排列。轮仓格不能占用。
4. 点击“合上箱子”评估，不会锁定局面。基本通关后继续优化旅途分。摄影、阅读、休息三种偏好赋予不同物品不同期待值，换偏好不会改变布局。
5. 种子挑战将车票整数映射为目的地、偏好和更严格的重量上限，共 27 种规则组合。相同号码的规则完全一致；它不生成无限随机地图。

旅途分 = max(0, 四舍五入(期待值 × 2 + 已用格数 − 缺项数 × 15 − 超重公斤数 × 20))。分数无百分制上限，通关须另行满足清单和重量。不同偏好及场景的最佳分分别本地记录。

## 运行、测试、构建

需要 Node.js 20+，没有第三方运行时或开发依赖。包含独立 package-lock.json，不依赖仓库 workspace。

```sh
cd demos/suitcase-stories
npm ci
npm test
npm run build
npm start
# http://localhost:4175 （可用 PORT=... 更换端口）
```

`npm run build` 将 `src/` 复制到独立 `dist/`。任意静态托管均可部署 dist 内容，不需要 API、账户、付费服务或密钥。项目使用相对资源路径，可部署在子路径。

公开体验：https://hakuya-suitcase-stories.golden-berry-3772.chatgpt.site

此 README 不声称该地址已上线。实际发布及在线浏览器验证由当天交付记录确认。

## 测试与人工验证

`npm test`：20 项 Node 原生测试，覆盖旋转、边界、碰撞、轮仓、移动不复制、移除与撤销、重量、需求、偏好评分、坏存档、序列化、3 组通关解和 27 种种子规则通关。另执行 `node --check src/app.js`、静态构建。单元测试不等同于浏览器交互验证；浏览器实测结果由交付记录列明。

便于浏览器检查的确定通关解，以下坐标为 **第几列、第几行，从 1 开始**，全部初始方向：

- 海边：手机(1,1)、衣物(2,1)、充电器(4,1)、雨衣(5,1)、浴巾(1,3)。重量3.2kg、13格、摄影期待13、旅途分39。再加相机(4,3)，摄影分71，切阅读变43，布局不变。
- 山中：手机(1,1)、衣物(2,1)、充电器(4,1)、徒步鞋(1,3)、围巾(4,3)、零食(4,4)。重量4.8kg、18格；轮仓(5,5)、(6,5)不可占用。
- 城市：手机(1,1)、衣物(2,1)、充电器(4,1)、雨衣(1,3)、耳机(3,3)。重量2.9kg、13格。

人工检查还应覆盖：空箱出发提示缺项、碰撞不改变布局、浴巾在第6列水平放置失败而旋转后能放、移动后撤销、取出后撤销、清空、刷新恢复、种子切换、窄屏操作、键盘方向键与 Enter 放置、R 旋转与 Escape 取消。超重允许暂存但禁止通关，可用山中多加相机、厚小说等触发。

## 数据、可访问性与限制

- 进度和个人最佳仅保存在浏览器 localStorage；无网络请求、分析、外部字体、外部图片、账号或服务器存档。存储不可用时仍可游玩，但刷新不保留。
- 键盘可遍历物品、按钮及所有格子；方向键在格子间移动；状态通过 aria-live 宣读。视觉同时用文字、勾号和颜色反馈。尊重减少动画设置。
- 旋转只调整待放物品，需再点击位置确认。改变目的地清空当前局面；撤销历史只保留当前页面会话，刷新恢复布局但不恢复撤销栈。
- 这是手工设计的小型优化游戏，不宣称评分为全局最优解；基础通关容易，兴趣在空间取舍与偏好策略。
