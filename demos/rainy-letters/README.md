# 雨夜来信 / The Letter in the Rain

一个可重玩的中文文学推理游戏。五位证人、八处线索、六次调查机会。玩家需要亲自把证据连接到判断，重建失踪告别信的去向，并决定如何讲述真相。

## 玩什么

- 免费听取五位证人的矛盾证词，再选择八处线索中的至多六处调查。
- 调查会消耗机会；复看、证据连线和重建核对免费。
- 证据桌要求直接依据，乱连线会阻止结案。仅猜对三个选项不能通关。
- 时间可通过直接记录或校钟推算证明，多条路线可解。
- 新增证词冲突推演：从三组矛盾中至少化解两组，听取双方原话，选择因果解释并配对直接证据。把“谁在说谎”改为理解时间来源、语言歧义和授权边界。
- 三种结局由证据完备程度与最后的伦理选择共同决定。
- 内置调查指南、实时预算、逐维复核、可确认的重启操作。当前页面状态不持久保存；刷新即重置。

故事、人物与城市均为原创虚构，不涉及真实事件。全部美术由本地 CSS 绘制，无外部素材、字体、跟踪或运行时 API。

## 运行

要求 Node.js 20+，无第三方依赖。

```sh
npm ci
npm run dev
# http://localhost:4173
# 自定义端口：PORT=4178 npm run dev
```

## 测试与构建

```sh
npm test
npm run build
```

Node 内置测试覆盖预算、证据有效性、时间矛盾、正确/错误重建、不同解法、三种结局和重置重玩。`build` 将四个必要文件复制到 `dist/`。不需要后端。

## 部署

把 `dist/` 内容部署到任意静态服务器或 GitHub Pages 子目录即可。资源全部使用相对路径，无构建环境变量或秘密。开发服务器只用于本地检查，不作为生产服务。

## 可访问性与界面

响应式纸张 / 雨夜视觉，原生按钮、单选与复选框、语义 fieldset、可关闭原生 dialog、可见焦点、状态播报与减少动态偏好支持。证据和选择不依赖颜色、悬浮或拖拽操作。支持键盘操作。

## 文件

- `engine.js`：无 DOM 的故事数据和状态引擎。
- `app.js`：界面与交互。
- `style.css`、`index.html`：响应式呈现。
- `test/engine.test.js`：自动测试。
- `SPOILERS.md`：完整推理、最小路线与结局说明，含剧透。
