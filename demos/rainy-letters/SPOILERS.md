# 剧透：雨夜来信的真相与路线

## 真实时间线

- 20:00：机械走廊钟比标准时间快十分钟，尚未修好。
- 20:50：林岚留便笺拒绝刊印，宣布取回借件并暂存回声书铺。
- 21:00：乔予离开。信仍在书房。
- 21:05：停电。林岚在停电发生后进入书房。
- 21:10：恢复供电。林岚带蓝封套离开；应急门与供电所记录为标准时间。门房看到的机械钟为 21:20。
- 21:12：步行两分钟后抵达回声书铺，寄存完整封套。司机按调度标准时间见到她。

“停电后”不等于“恢复供电后”，“钟面时间”不等于标准时间。林岚强调封套，但封套装着信，她并未否认携带。借展只允许展示封套，不允许公开信件或出售。她取回自己的借件，是为了保护未获授权公开的私人告别。

## 正确重建

人物：林岚。时间：21:10。动机：取回私信，阻止未经同意的公开。

每一维须有直接支持的证据连线。所有不成立的连线必须移除。证据规则公开且确定，没有随机真相。

### 可支持的判断

| 证据 | 可连判断 |
| --- | --- |
| 门房出入簿 | 林岚拿走封套 |
| 校钟便条 | 钟快十分钟 |
| 末班车调度条 | 林岚拿走封套；21:10 移出 |
| 供电检修单 | 林岚拿走封套；21:10 移出 |
| 借展单末页 | 阻止未经同意的公开 |
| 晚报校样 | 阻止未经同意的公开 |
| 书铺寄存回执 | 林岚拿走封套；信在书铺完好 |
| 未寄出的短笺 | 阻止未经同意的公开 |

晚报校样和短笺只能证明保护信件的计划，不能证明计划已经完成。只有书铺寄存回执能够证明信的完好现状。

### 路线 A：精确记录

调查供电检修单、借展单末页、书铺寄存回执。连线：供电→人物+21:10；借展→动机；回执→完整。正确重建后选择私人告别，获得“避雨处”。剩余三次机会可用于交叉验证。

### 路线 B：校钟推算

调查门房出入簿、校钟便条、借展单末页。连线：簿→人物；钟→钟快十分钟；借展→动机。引擎可据门房 21:20 减十分钟推出 21:10，无需供电或电车记录。选择私人告别得“留白”；增加寄存回执并连到完整可改为“避雨处”。

### 路线 C：街道时间

调查末班车调度条、晚报校样。调度条→人物+21:10；校样→动机。两处即可推导核心真相，但仍需寄存回执才能获得“避雨处”结局。其余预算可调查书房各人的说法。

## 三个结局

- 一封信的避雨处：正确、有证据的重建 + 完整/去向连线 + 私人选择。
- 把句号留到明天：正确、有证据的重建 + 尚无完整连线 + 私人选择。
- 明日头条：正确、有证据的重建 + 公开选择。说明曝光未经授权的拍卖计划的价值，以及公开私人悲伤的代价。

没有“真相随机换人”的伪重玩。重玩来自调查顺序、证据组合、额外佐证和最后的选择。


## v2：证词冲突推演（结案必需）

除三个结论及连线外，还须化解以下三组中的至少两组。听取双方原始证词是理解上下文的前提，证据配对必须正好匹配，不能混入其他材料。

- 两种钟：听顾叔、沈絮；解释选“机械钟快十分钟”；配对门房出入簿 + 校钟便条。
- 停电后的含义：听林岚、顾叔；解释选“断电发生后进入，恢复供电时离开”；配对供电检修单。
- 借展与同意：听林岚、周禾；解释选“借展范围未含刊印”；配对借展单末页 + 晚报校样或未寄出的短笺。

上文 A/B/C 路线仍描述基础事实证明，现在还需补足冲突推演。例如 A 加入未寄出的短笺，共四次调查，即可同时化解“停电”与“授权”，并保留完整回执得避雨处结局。B 加入短笺，共四次，化解“钟表”与“授权”，再加回执共五次可得避雨处。也可通过出入簿 + 校钟便条 + 供电检修单化解两组时间冲突，再用校样说明动机，最后用回执确认完好，共五次。

错解不会扣时间，但必须修正；听取或重听证词不会扣调查预算。
