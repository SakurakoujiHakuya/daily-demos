# 图片轻装

本地图片缩放、压缩与格式转换。选择图片或使用原创示例，比较原图和处理后的体积，再下载真实文件。没有账号、服务器上传或追踪脚本。

## 运行
Node.js 20+，无第三方运行或开发依赖。
```sh
npm ci
npm test
npm run build
npm run dev
```
打开 http://localhost:4173 。`dist/` 可由任意静态服务独立部署。

## 使用
- 拖入或选择图片；默认等比缩至最长允许宽度 1280 px，不放大。
- 调整宽度、WebP/JPEG/PNG 格式与有损格式的画质；结果即时更新。
- 原图始终保留，可重置设置，下载文件不会覆盖原文件。
- 最大输入 25 MB / 2400 万像素；宽度最大 8192 px。SVG 不接受。
- JPEG 的透明区域转为白色。GIF 只保留一帧。输出不保留原始元数据/动画；浏览器重编码可能改变色彩。PNG 不提供有损质量设置，可能比原图更大。实际输出 MIME 决定扩展名，格式回退会提示。
- 页面及程序会从网站加载；图片处理本身仅在本地浏览器，不上传文件。原图和结果保留于当前页面内存，关闭页面即释放。

## 测试
`node --test` 覆盖尺寸/比例、文件限制、实际格式文件名和体积变化。浏览器实测记录见 QA.md；单元测试不能代替浏览器编码/下载验证。

## 部署
静态文件通过 Sites 官方 source/package/save/deploy 工作流发布。`.openai/hosting.json` 声明 Site 与 dist。实际地址和部署状态见 deployment-info.json。源代码同步至 GitHub `demos/image-light`。
