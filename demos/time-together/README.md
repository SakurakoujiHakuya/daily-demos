# 一起几点

一个本地运行的跨时区共同空闲规划器。选择参考日期、时长和城市的可用时间，直接在时间带或候选时段中选时间，下载本地 `.ics` 文件。没有账号、后端、邀请发送或第三方统计。

## 运行与测试

需要 Node.js 20+（浏览器计算需要现代 Intl / IANA 时区支持）。无第三方依赖。

```sh
npm ci
npm test
npm run dev # http://localhost:4173
npm run build # dist/ 可独立部署到静态主机
```

每个项目独立安装、测试和构建；不依赖仓库根 workspace。`package-lock.json` 固定零依赖安装。

## 使用

1. 左上选择日期、参考城市和会议长度；候选开始时刻按照该参考城市显示。
2. 编辑各城市的可用时间。结束早于开始表示跨午夜；开始等于结束表示全天。
3. 点击候选时段，或在色带中检查任意时刻。只有全程所有城市均可用时才允许导出日历。
4. 可添加最多 6 个城市；设置保存在本机 localStorage。恢复示例可清除自定义组合。

## 日期与夏令时

计算建立在 UTC 绝对时间线上，逐分钟检查所有参与城市的可用窗口，再以 Intl 映射当地日期、时刻与偏移。一天按参考城市的本地日历日期界定；DST 切换日可能有 23 或 25 小时。参考时区可选集的现代偏移均是 15 分钟的倍数，日界扫描以 15 分钟为粒度；候选开始每 30 分钟一个。重复本地时间的按钮标题/无障碍名称以及选中结果包含 UTC 偏移；不存在的当地时刻不会生成。未来时区规则依赖用户浏览器自带的 IANA 数据；不承诺未来政治变更准确性。

日期输入范围 2020–2040；当前版本不提供节假日/周末排除、个人日历联动或每人独立指定日期。色带对应同一绝对时间线，各地日期可能不同。每人可用时间作为每日重复窗口处理。日历下载为 UTC `DTSTART/DTEND`，不添加 ATTENDEE、不发送邀请。

## 验证

`npm test`：27 项 Node 内置测试，含伦敦/纽约 DST 23/25 小时日、重复/缺失时刻、加德满都 45 分钟偏移、跨午夜、无交集、整段可用性、日界与 ICS 内容、UTF-8 75 字节折行及 CRLF。浏览器实测单独记录于 `QA.md`，不以单元测试代替。

## 部署

`npm run build` 生成纯静态 `dist/`。本作品公开发布到 Sites，准确 URL/项目与版本 ID 见 `deployment-info.json`。源代码与 `.openai/hosting.json` 保留独立部署配置。无需运行时密钥、付费服务或新增凭据。

城市/时间设置仅保存在当前浏览器；不上传个人日历或联系人。界面、逻辑及文案为本项目原创，MIT 开源。时区计算由浏览器 Intl 提供，无拷贝第三方网站资产。设计借鉴工具型界面的任务优先与渐进披露原则，不复制品牌资产。
