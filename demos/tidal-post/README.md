# 潮汐邮差

原创、浏览器本地的潮汐路线策略游戏。三幅岛屿地图中，选择送信次序、预测下一拍潮水、在邮局和避潮亭恢复体力，送完所有信后返回邮局。不是实时计时，玩家操作才推进游戏。

## 核心玩法

- 六拍循环：低、低、中、高、高、中。普通浅滩在低/中潮可走，低潮滩只在低潮可走；走入格子按**下一拍**判断。
- 方向移动或等一拍消耗1体力。歇脚只能在邮局/避潮亭，恢复4点体力但推进一拍。
- 不能走入下一拍被淹的格子，不扣行动；站在滩上等到涨潮会失败。失败可撤回，不强制重开。
- 送达自动拆开一段原创短笺。全部送达仍需归航。路线效率决定星级，最佳拍数保存在当前浏览器。
- 三图是不同路线结构：分支短路、环岛折返、多重低潮窗口。可改变出发时机、投递顺序、补给点反复探索。
- 一步建议用确定性广度优先搜索计算当前状态的可行路线，不随机、不联网生成，也不自动执行行动。

## 运行

Node.js 18 或以上，无第三方依赖。独立包，不依赖仓库 workspace。

```sh
npm ci
npm test
npm run build
npm start
```

打开 http://localhost:4173 。用 `PORT=4174 npm start` 更换端口。服务器仅提供 dist 中的构建文件，404 不回退为首页。

## 操作

相邻格点击、方向按钮或键盘箭头移动；空格等候，R 歇脚，Z 撤回。聚焦按钮时空格保持按钮原生激活行为。重走仅重置当前局面，切换地图清空当前路线，不清空最佳纪录。

## 文件与部署

- `src/engine.js`：纯规则、地图、可行路线求解器。
- `src/app.js`：地图、预报、操作、反馈与本地最佳纪录。
- `scripts/build.js`：复制静态输出至 dist。
- `scripts/serve.js`：最小本地静态服务器。
- `test/engine.test.js`：规则、边界、三关通路和另类出发路线。
- `QA.md`：实测边界及供浏览器验证的明确步骤。

可将 dist 目录部署至任意静态主机。正式托管由上层交付任务登记；不要把本地构建成功视为公网部署成功。无需账户、API、凭据、数据库或付费服务。无外部字体、图片、CDN依赖。

## 数据与限制

只把每幅地图最佳拍数写入 localStorage (`tidal-post-records`)。不上传、不跨设备同步，不保存进行中的局面，刷新会回到第一关。禁用存储时仍可正常游玩。所有地名、信件与玩法为原创虚构，不是真实海岸通行或潮汐安全指南。
