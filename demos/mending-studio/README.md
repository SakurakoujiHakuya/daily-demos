# 补丁缝纫铺 / Mending Studio

一个不计时的连续线网格缝纫谜题。用一根线沿针点间的边行走，在有限线长与张力中加固裂口。三个原创委托与自由布片，中文界面，零运行时依赖。

## 运行、测试、构建

需要 Node.js 18+。不需要安装依赖；提供 package-lock.json 供可复现的常规 npm 流程使用。

```sh
npm start                 # http://localhost:4181，从源码运行
npm test                  # Node 内置测试器；37 个测试
npm run build             # 生成 dist/，可以静态托管
SERVE_DIR=dist npm start   # 验证构建产物
# PORT=5000 npm start      # 可选端口
```

源码与发布 checkout 分离；此目录不包含 Site hosting manifest、Git 元数据或凭据；`deployment-info.json` 仅记录公开发布标识和验证结果。`dist/` 是生成物，不纳入源码。无需外部字体、CDN、图像或网络请求。

## 怎么玩

- 布面是 4×4 格，针点是 A–E 列、1–5 行；布格以其左上角命名。
- 从「起」针点开始，点击相邻针点（也支持鼠标连续拖过针点），或键盘 Tab 聚焦针点、Enter 落针、方向键继续。手机可以逐点轻触。
- 一条边耗费 1 格线；每转弯加 1 张力，每重新经过一个旧针点再加 2。不可跳格、斜走、重复使用边或穿过灰色扣带。
- 一条针迹同时给两侧布格各增加一边支撑。裂口上的 `已缝 / 所需` 达标后变绿；多缝的边不会扣分。
- 缝牢所有裂口，到达「收」，再按 **收针验收**。超过预算的下一针会被拒绝，不会破坏已有线路。
- **撤销一针** 精确退还线长和张力；**重新起针** 清空当前针迹。切换委托会清空当前针迹，不清空完成记录。
- 自由补丁：任意起止；点「编辑裂口」后点布格按 `无 → 需两边 → 需三边 → 无` 循环。清空裂口后可单纯画连续线。验收后可下载 SVG 留念。
- 线色只改变外观，不影响规则。完成记录保存在当前浏览器 localStorage（版本键 `mending-studio-v1`），不保存进行中的针迹，不上传任何数据。

## 三件委托与一组参考解

只在需要时看；每件都至少有两条经自动测试验证的路线。路线写的是**针点**。

| 委托 | 参考路线 | 用线 / 张力 |
|---|---|---|
| 袖口的四道裂纹 | A2 → A3 → B3 → B2 → C2 → C3 → D3 → D2 → E2 | 8 / 7 |
| 口袋的两座小岛 | A3 → B3 → B2 → C2 → C3 → C4 → D4 → D3 → E3 | 8 / 6 |
| 风衣上的远行地图 | A1 → B1 → B2 → C2 → C1 → D1 → D2 → D3 → C3 → B3 → B4 → C4 → D4 → E4 → E5 | 14 / 9 |

第二种口袋路线是不同取舍：A3 → B3 → B2 → C2 → C3 → D3 → D4 → C4 → C5 → D5 → E5 → E4 → E3，耗线 12 / 张力 9，仍在上限内。所有参考解在 `engine.js` 的 `solutions` 中，可独立验证；UI 只提供思路提示，不自动替玩家作答。

## 工程结构

- `engine.js`：纯函数规则、委托数据、预算 / 覆盖计算、非破坏性行动验证。
- `app.js`：SVG 布面、无框架交互、键盘操作、配色、浏览器本地完成记录和 SVG 导出。
- `styles.css`：原创纸张 / 亚麻视觉，响应式三栏工作台、窄屏布局和减少动画支持。
- `test/engine.test.mjs`：37 个测试，含六条完整解、不同成本的解、非法移动、扣带、重复边、转弯 / 重访张力、预算边界、共享边覆盖、起终点验收、撤销、自由编辑、不可变性；400 轮固定随机种子的状态不变量验证（28,000 次尝试）。
- `scripts/build.mjs` / `scripts/serve.mjs`：仅使用 Node 标准库的构建和静态开发服务器。

## 边界

这是抽象网格谜题，不是现实缝纫教学或布料物理模拟。无账号、云同步、计时、广告、付费项或真实服装数据。自由设计有 40 格线 / 28 张力上限，未使用无限预算。完成记录为此设备此浏览器所有；清理站点数据会移除记录。SVG 下载由浏览器处理，非自动上传。
