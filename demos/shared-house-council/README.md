# 合租公约实验室 / Shared House Council

原创的四周共居策略实验。四名虚构室友有不同生活偏好和可承担的劳动量。玩家不是选择预写对白，而是调整安静时段、访客、清洁标准、逐人的劳动与补偿，以及公共投资，让一份份公约获得支持。每项操作立即改变分数与投票，提交之后改变信任、整洁度和下周预算。

目标不仅是凑够三票：稳定结局要求四周全部通过、所有人信任至少 45、整洁度至少 65。牺牲同一个人的多数决，可能每周都通过但仍留下裂缝。

## 本地运行

需要 Node.js 20 或更高版本。

```sh
npm ci
npm test
npm run build
npm start
```

访问 http://localhost:4187 。可用 `PORT=8080 npm start` 更改端口。无需跨项目 workspace。锁文件独立，当前没有第三方依赖。

## 如何玩

1. 选择开局与事件种子。相同种子对应相同的四周事件，方便比较策略。
2. 调整生活约定、三个公共投资，以及四人的劳动格数、补偿枚数。
3. 展开“为什么投这一票”，检查不同人对每项取舍的反应。选择一位倾听对象可以获得一次本周的意愿加成。
4. 劳动足额且预算未超支才可提交。少于三票的提案仍可主动提交，但会被否决。
5. 通过后，赞成者信任增加，反对者降低；被过度安排劳动的人还有额外惩罚。拒绝后无人承担公共劳动，整洁度与所有人的信任下降。
6. 观察新的每周事件，继续调整，或者将以前的公约作为草案重新修改。草案可以撤销，已提交结果不可撤销。
7. 四周结束后获得稳定、仍需修改、分歧留下三种不同结果。相同种子重开可探索另一条路线。

## 透明规则

- 每周基础预算 12 枚，加上上周结余（最多 8）；水管漏水事件先扣 3。
- 劳动需求 = 6 + 清洁标准 × 2 + 事件需求 − 清洁工具 × 2。
- 隔音脚垫、清洁工具、共同晚餐各 2 枚；每人补偿 0–3 枚。
- 每人的意愿从 52 开始，受信任、安静时段距离、访客偏差、清洁期待、劳动量影响；补偿每枚 +7，认真倾听 +10；公共投资按对应偏好加分。
- 超过本周能力的劳动，每多 1 格额外 −25 意愿。所有分项在 UI 内公开。
- 意愿 ≥40 即赞成；至少 3/4 票通过。
- 通过：赞成者信任 +6、反对者 −7；超负荷额外 −5。整洁度增加 `清洁标准 × 7 − 8`。
- 否决：所有人信任 −6、整洁度 −15。未实施投资，未用预算保留但仍受结余上限约束。
- 游戏总计四周，不需要等待现实时间。

## 存档与隐私

浏览器 localStorage 保存本机局面与草案。不向服务器发送玩家内容，不使用追踪脚本。刷新后重放已提交公约恢复状态。新一局替换当前本机存档。清除站点数据会丢失存档。

## 测试与验收

`npm test` 使用 Node 内置测试运行器。覆盖确定性事件、非法预算与劳动、逐项分数、补偿/倾听/超负荷、不可变状态、少数者信任、多结局、三个开局可解、四周终止和结余上限。

`test/routes.json` 记录三种开局各自的稳定路线，作为回归测试和浏览器人工验收参考。它不是游戏内“自动通关”。

浏览器验收应独立确认：操作即时刷新票因、预算不足禁用提交、撤销草案、至少一条稳定与一条破裂路线、刷新恢复、移动布局。单元测试不能代替浏览器实测。部署后的浏览器验收结论以当天交付记录为准。

每周设置：安静 23、访客 4、清洁 1、劳动 6 / 6 / 0 / 0、补偿全 0、不勾公共投资、不选择倾听。重复提交四周（每周重新设置或从历史复制草案）。

预期四周全部否决，终局通过 0 份，整洁度 0，分歧留下结局。此路线展示把负担压给两个人无法换来共同生活。
