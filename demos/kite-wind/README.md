# 借风放纸鸢 · Kite Wind

一款不赶时间的回合制牵线小游戏。每次左牵、右牵、放线、收线或稳住，纸鸢都会受到本拍气流的共同影响。目标不是按顺序阅读故事，而是规划高低往返的路线，接住四枚风笺，同时管理拉力、体力与有限步数。

## 玩法与深度

- 三种固定但不同的风况：河堤初风、海岸阵风、暮色回流；可查看未来四拍的方向与升降。
- 放线升高、收线降低；收线和强风增加拉力。连续三拍拉力达到90会断线。稳住恢复体力并缓解拉力，但仍会被风带走。
- 四枚风笺必须依次收集，目标高低交错，不能只不断放线；进入圆环即可接住。
- 每个操作立即反馈位置、线长、拉力、体力和航迹。可撤回一拍、重新放飞、切换风况，比较最优步数与本机最高分。
- W/A/S/D、方向键、空格，或页面按钮均可操作。完全回合制，不操作就暂停，无强制等待或实时倒计时。
- 数值是为策略玩法设计的抽象模型，不是现实风筝飞行或安全训练模拟器。

## 独立运行

Node.js 18及以上；无第三方运行时或开发依赖，使用独立 package-lock.json。

```sh
npm ci
npm test
npm run build
npm start
```

访问 http://localhost:4173 。可用 PORT 环境变量更换端口。dist/ 是独立静态部署目录，可托管于任意支持静态文件的站点；无后端、密钥或付费服务。

## 验证

npm test 运行 Node 原生测试，包括三种风况从初始状态到四枚风笺胜利的完整合法路线、初始状态断线策略、状态边界、存档校验、终局冻结和确定性风况。构建检查会生成 dist/。

单元测试不代替浏览器实测；本项目的在线地址和最终浏览器验收结果由当天交付记录补充。

## 数据与许可

存档及个人最好成绩仅保存在浏览器 localStorage；无登录、分析埋点、上传或外部字体。刷新可继续当前局，但撤回历史只存在当前页面会话。更换风况或重新放飞会清空当前局；浏览器清除本站数据可删除所有存档与成绩。所有图形由本项目原创SVG/CSS绘制，无外部图片与私人信息。原创代码、文字和图形采用 MIT 许可，见 LICENSE。
