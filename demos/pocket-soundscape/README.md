# 口袋声景 · Pocket Soundscape

把脚步、钥匙、细雨、杯沿、单车铃声与翻页沙沙编成一段可循环的小城。全部音色由 Web Audio 振荡器和噪声实时合成，没有录音、外部素材或服务。

## 核心玩法

- 六轨 × 十六格。点格子循环「留白 → 轻触 → 重音」，即刻影响下一次播放。
- A/B 独立段落，支持 A、B、AB、AABB 循环；复制、整段移位、清空和 60 步撤销。
- 50–160 BPM、摇摆、音高、总音量、每轨音量、静音与独奏。静音优先于独奏。
- 三个不同风格的起点。删去重拍、加入切分或改变 B 段尾声，会得到不同的节奏与结构。
- 自动本地保存、验证后的 JSON 导入/导出。文件只在当前设备读取，不上传；JSON 是编排数据，不是音频录制。
- 仅视觉模式可在无法播放声音的环境体验节奏。方向键移动格子焦点，空格编辑；所有控件均可键盘操作。

## 本地运行

需要 Node.js 20+。无第三方依赖，不需要下载运行包。

```sh
npm ci
npm test
npm run build
npm start
# http://localhost:4173
# 修改端口：PORT=4180 npm start
```

`src/` 是源文件，`dist/` 为独立静态站点输出。`npm run build` 不依赖其它 demo 或 workspace。锁文件随本项目提交。

## 部署

将 `dist/` 内容放到任意支持 HTTPS 的静态网站根目录。无需后端、环境变量或凭据。

公开体验：https://hakuya-pocket-soundscape.golden-berry-3772.chatgpt.site

## 测试与验收

`npm test` 使用 Node 内置测试器，覆盖不可变编辑、格子边界、摇摆总时长、段落循环、静音/独奏优先级、预设差异、环形移位、JSON 往返与恶意/错误输入。

浏览器验收流程：
1. 开启「仅视觉」并播放，确认播放游标从 A 的 16 格进入 B，暂停后游标停止，停止归零后从第一格重新开始。
2. 点击 A 第一个格子三次，观察轻触、重音、留白循环；撤销恢复上一步。
3. 复制 A 到 B，切换 B 修改尾声，选择 AABB，观察四小节轮换；A 的内容不随 B 修改。
4. 静音、独奏与每轨音量修改有可见状态反馈；同时静音+独奏的轨道不响。
5. 修改速度和摇摆，观察播放速度/长短交替变化。启用音频需真实用户点击；应人工确认音色、音量及节奏，不能以单元测试代替听觉验证。
6. 导出、改动、重新导入，确认恢复；导入错误 JSON 保持现有作品并报错。刷新后恢复本地保存。
7. 移动视口横向滚动网格，页面本身不横向溢出。键盘方向键移动网格，空格切换。
8. 播放时切换后台标签页，自动暂停，返回后需要点击继续。

实际浏览器/线上验收结果在当天交付记录另行记录，不将上述计划视为已通过。

## 已知边界

播放使用浏览器前台定时器，不是专业 DAW 的采样级调度。系统繁忙可能有轻微抖动；后台自动暂停以避免延迟堆积与意外发声。音色需浏览器支持 Web Audio。音频输出受系统静音、浏览器策略及设备影响。保存仅限当前浏览器，清理网站数据会删除它，请导出保留。
