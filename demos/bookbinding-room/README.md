# 旧书装帧室

2026-10-24 原创浏览器拼版 / 配帖谜题。交换页片、修正倒置、移动整张纸的套帖位置，再试折校对。三本原创图文小书分别为 8 / 12 / 16 页；六种初始散页排列，可反复探索不同整理策略。

## 运行

需要 Node.js 18 或更新版本。无第三方运行时依赖，无外部图片或字体请求。

- `npm ci`
- `npm test`
- `npm run build`
- `npm start`，访问 http://localhost:4175
- 自定义端口：`PORT=4176 npm start`

每个项目独立安装、构建、测试。生产目录 `dist/` 可部署到任意静态托管；JS 使用 ES modules，因此不要直接以 file:// 打开。Sites 部署由 `.openai/hosting.json`（登记时生成）绑定，托管 dist。MIT 授权适用于原创代码、图形与文字。

## 怎么玩

1. 正面和背面各有两张页片。点一张选中，再点另一张交换。切换纸张后仍保留选择，可跨纸张交换。
2. 倒置的页片选中后点击“旋转选中页 180°”。
3. 整张移向外层 / 内层会同时移动其四页；右侧实时按照当前套帖位置生成阅读顺序。
4. “给一点线索”说明选中位置应放哪页及同面配对关系，不自动完成。
5. 试折校对：所有阅读位置的页码与方向吻合才算完成。无时限，无惩罚，可撤销最近100次操作。
6. 切换委托会开始该委托的新局；“重置本局”恢复当前排列，“另一叠散页”循环六种排列。只有当前一局保存在浏览器，退出后可恢复；撤销历史不跨刷新保存。
7. 导出 JSON 配帖记录（不是印刷 PDF，含当前状态与标准拼版供学习）；无上传、账号、排行榜或后端。

## 数学模型与边界

使用 N 页、N/4 张纸的单次对折套帖模型，每张纸四页。第 i 张（从外向内，i 从0开始）的 [正面左, 正面右, 背面左, 背面右] 为 [N−2i, 1+2i, 2+2i, N−1−2i]。背面是沿竖边翻纸后的正视图，所有页顶应朝上。每面左右页码和为 N+1。读取函数是此映射的逆，纸张换层会改变真实阅读顺序。本作不模拟多次折页、出血、爬移、纸纹、锁线或完整印刷生产。

## 测试与真实浏览器核验

`npm test` 覆盖三套标准拼版、全部18个初始局合法操作求解、换页、旋转、整张换层、无效动作、保存数据校验及阅读顺序。单元测试不代表浏览器实测；公开页面的实际浏览器核验记录由当日交付 QA 补充。

### 浏览器 QA 可复现流程

- 初始雨后散步布局：第1张正面 [7倒置,6]；背面 [3,4倒置]；第2张正面 [5,8]；背面 [1倒置,2]。
- 按目标配帖整理为第1张正面 [8,1] 背面 [2,7]，第2张正面 [6,3] 背面 [4,5]，全部朝上。跨页交换方式：选中一页，再切纸张，点击目标页。
- 12页目标：第1张 [12,1,2,11]；第2张 [10,3,4,9]；第3张 [8,5,6,7]。
- 16页目标：第1张 [16,1,2,15]；第2张 [14,3,4,13]；第3张 [12,5,6,11]；第4张 [10,7,8,9]。
- 完成后把任意一页旋转，校对应失败；撤销再校对应成功。把整张纸移层，阅读顺序随之变化，撤销复原。刷新验证保存，导出验证 JSON 可读。

## 文件

- `engine.js`：纯函数拼版、状态校验、动作、阅读顺序、评分与求解器（求解器只用于测试，没有自动通关按钮）。
- `app.js`：界面、撤销、本地保存及导出。
- `test/engine.test.js`：确定性测试。
- `scripts/build.js` / `serve.js`：独立静态构建与开发服务器。
