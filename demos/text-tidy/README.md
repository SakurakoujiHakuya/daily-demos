# 文字整理台

浏览器本地文本整理工具。粘贴原文，选择整理空白、PDF 断行或统一列表，对照结果后复制或下载 UTF-8 TXT。保留原文，可撤销输入、清空和“用结果继续整理”；关闭页面不保留内容。无上传、无账户、无分析脚本。

## 运行与测试

Node.js 20+；无第三方运行时或开发依赖，各项目独立。

```sh
npm ci
npm test
npm run build
npm start
# http://localhost:4173，PORT 可覆盖默认端口
```

`dist/` 为完整静态发布目录。`engine.js` 是可独立测试的纯函数，`app.js` 只负责交互。单元测试覆盖 CRLF、Unicode、空行、内容保留、可选空格压缩、PDF 段落/标题/列表边界、无序符号、幂等与统计。不把这些单元测试称为浏览器测试，实际浏览器结论见 QA.md。

## 规则与边界

- 默认只清理行首尾普通空白并压缩多余空行，保留一个段落间空行；不默认折叠内部空格。
- PDF 断行是启发式，不保证识别所有版面。明确选择后才拼接非空相邻行；空行、标题、列表、中文句末标点保留边界。用户须对照原文确认；不会删除连字符或智能改写文字。
- 列表只将常见无序符号统一为 `-`，不会重编号。
- 最多 100,000 Unicode 码点，超出时保留输入但停止输出，避免卡顿。行级差异按行号对照，最多显示 50 处，非最短编辑距离算法。
- 文本复制需浏览器剪贴板权限与用户点击；失败时选中结果供手动复制。下载的内容是当前结果，不会自动发送给他人。
- 浏览器本地处理不等于安全加密存储；未启用持久化，不建议在共享设备粘贴敏感信息。

## 部署

`.openai/hosting.json` 保存唯一 Sites project_id；`npm run build` 后通过 Sites 官方源码/打包工作流同步 source，再保存 archive-backed 版本并发布 public。状态和实际公开 URL 见 `deployment-info.json`。无需密钥、数据库、付费服务。
